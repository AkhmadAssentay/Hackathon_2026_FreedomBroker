# Эталонная разметка (gold set)

20 диалогов из DEV, которые люди оценивают вручную по чек-листу. С ними сравниваются оценки модели, чтобы получить честные цифры качества по каждому критерию и языку.

## Как размечать

1. Откройте `gold_labels.csv` в Excel или Numbers (разделитель — точка с запятой).
2. Для каждого диалога откройте его текст (`DEV_dataset/texts/<id>.txt`) или карточку в приложении.
3. Заполните столбцы `c01`–`c08` по чек-листу из PDF. **Не смотрите на оценку модели до разметки** — иначе разметка подстроится под модель.
4. Сохраните файл в том же формате CSV.

| Столбец | Критерий | Допустимые значения |
|---|---|---|
| c01 | Установление контакта | `yes` / `no` |
| c02 | Выявление потребности | `yes` / `no` / `na` |
| c03 | Идентификация | `yes` / `no` / `na` |
| c04 | Консультация | `0` / `5` / `10` / `15` / `20` / `na` |
| c05 | Эмпатия | `yes` / `no` |
| c06 | Управление диалогом | `0` / `4` / `7` / `10` |
| c07 | Завершение | `yes` / `no` / `na` |
| c08 | Грубые ошибки | `yes` (есть нарушение) / `no` |

Можно писать и по-русски: `да`, `нет`, `н/п`. Пустую строку отчёт пропускает, поэтому размечать можно частями. Если сомневаетесь, напишите в `comment`. Лучше, если каждый диалог независимо разметят два человека, а спорные случаи вы обсудите.

## Как получить отчёт

1. В приложении оцените эти 20 диалогов (или весь DEV).
2. Запустите:

```bash
npm run gold
```

Отчёт печатается в терминал и сохраняется в `gold/report.md`. В нём:
- совпадение с людьми и каппа Коэна по каждому критерию;
- **ложное «Нет»**: модель снизила оценку там, где человек поставил «Да». Это несправедливый штраф оператору;
- **ложное «Да»**: модель пропустила нарушение;
- ошибки с N/A;
- совпадение по языкам (RU / KZ / EN) и средняя разница итогового балла.
